# 🧩 Gerador de Atividades Desplugadas

Aplicação web interativa para criar planos de aula e atividades de **Computação Desplugada** (sem necessidade de computadores para os alunos). Ideal para professores planejarem dinâmicas rápidas e práticas de pensamento computacional.

## ✨ Funcionalidades

- **11 Habilidades de Pensamento Computacional:** Algoritmos, Decomposição, Padrões, Abstração, Condicionais, Laços, Depuração, Binário, Variáveis, Funções e modo *Surpreenda-me*.
- **Personalização para a Turma:** Ajuste por nível escolar (Anos iniciais, Anos finais ou Ensino médio), duração (15 a 60 min) e formato (individual, duplas, trios ou equipes).
- **Material Completo:** Gera automaticamente o roteiro da aula, gabarito e um desafio extra em Python pronto para rodar no Google Colab.
- **Histórico da Sessão:** Permite reabrir rapidamente atividades geradas durante o uso.

## 🚀 Como usar

1. Abra o arquivo `index.html` diretamente no navegador (não requer instalação ou servidor).
2. Selecione uma habilidade de computação.
3. Configure o nível, o tempo e a organização da turma.
4. Clique em **Gerar atividade**.
